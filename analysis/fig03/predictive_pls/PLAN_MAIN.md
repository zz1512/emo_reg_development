# 宽范围解剖 PFC：PLS 主分析实现方案

版本：2026-11-11，供实施前对齐。本文为实现规格。预测、重抽样和结果表代码已经按本规格落地；Donahue 掩膜和 midthickness 不在仓库内时，空间定义步骤会停止，正式 OOF 与区间尚未在真实样本上跑完。
本轮范围仅包含432、FD≤0.5、宽范围解剖PFC主分析；不同时开发其他PFC定义、232、其他FD阈值或Ridge稳健性分析。

## 1. 问题、假设与结论边界

主要问题：在协变量和预定义PFC分区信息之外，其余脑区是否提高跨站点重评成功预测？
主假设为 `ΔR²_success = R²_M2 − R²_M1 > 0`，重评成功为唯一确认性主要终点。
年龄采用相同四模型作预先指定的次要分析，描述可泛化年龄信息；其区间作为辅助结果，不据此增加第二个确认性主张。

神经增量同时参照协变量模型M0。仅有M2优于一个预测很差的M1、但M2没有优于M0，不能宣称神经指标已提供可靠的行为增量价值。
未发现增量不能证明PFC与全脑等效；年龄预测提高不能证明脑活动解释了年龄相关行为发展，也不能证明因果性或网络重组。

## 2. 数据与目标

### 输入

- 沿用原432、FD≤0.5年龄分析的 `inputs/`：`design.csv`、`parcel_response.csv`、`parcel_info.csv`、`tian_combined.json`。
- X为被试×432的原始分区contrast均值，方向与缓存一致：重评负性减观看负性，
  即 `effectSize-reg_neg_Observe_across_runs − effectSize-pas_neg_Observe_across_runs`。

- 432为Schaefer400皮层+Tian32皮层下，不包括小脑；不另外拼接7网络、4系统、6杏仁核聚合均值。
- 行为沿用 `er_profiles_new.csv`；`er_profiles.csv`仅按用户已确认的逐行对应关系提供每行前六位真实ID。

### 两个目标

| 任务 | 目标 | 协变量（另含截距） |
| --- | --- | --- |
| 重评成功，主要 | `reappraisal_success` 原分数、原单位 | 年龄的固定低维三次样条、gender、parent_edu、meanFD |
| 年龄，次要 | design中的年龄，单位年 | gender、parent_edu、meanFD |

## 3. 宽范围解剖 PFC 的空间定义

主定义采用Donahue et al. (2018)的**双侧liberal PFC**，不按本样本激活或年龄/行为显著性选区。
来源：[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5984508/)，[作者Fig.1数据](https://balsa.wustl.edu/GrK7)。
以作者原始空间资源/明确的MMP成员列表复现其liberal边界，不能用“全部额叶”或名称中的PFC/OFC替代。
若作者资源尚未取得，空间制作步骤停止并说明缺什么，不自动切换到另一个定义。

空间实现顺序：

1. 保存来源、下载版本、MMP成员、结构信息和SHA256。优先使用同一套双侧fsLR32k皮层标签。
2. 与本工程 `Schaefer2018_400Parcels_7Networks_order.dlabel.nii` 对齐。
   不混用Kong2022/17Networks的编号；核对当前原生dlabel与既有volume缓存中的1..400编号及名称。
3. 用同网格midthickness顶点面积计算每区PFC覆盖率：
   `f_j = Σ(vertex_area × PFC_mask) / Σ(vertex_area)`，分母仅含该Schaefer分区的有效皮层顶点。
   不用inflated表面面积；若缺少midthickness/匹配面积文件，补齐模板后计算，不悄悄改成顶点计数。
4. **固定多数面积规则：f_j≥0.50归PFC，f_j<0.50归非PFC。** Tian401..432均为非PFC。
   无有效面积/标签缺失直接报错，不猜测归属。所有分区保存覆盖比例；`0<f_j<1`标为跨界，
   另标记`0.20≤f_j≤0.80`供重点空间核查。核查配准与标签正确性，不按预测结果人工改组。
5. 输出每区编号、原名、半球、覆盖比例、组别、跨界标记、规则及来源；检查两组不重叠且并集为432。
6. 本地输出PFC/非PFC原生dlabel、必要的左右半球label和SVG空间预览，确认没有左右脑/网格错误。

此映射定义的是“PFC分区集合”。跨界分区已有的均值无法精确拆成PFC/非PFC体素，因此结论表述为
“超出预定义PFC分区集合的增量预测信息”，不宣称完成了精确到每个体素的PFC信息分离。
空间归属在本地独立确定，服务器直接按parcel编号索引既有432列，不重提被试均值或把体积数据重新投影成表面特征。

## 4. 四个模型

| 模型 | 基础预测 | 神经特征 |
| --- | --- | --- |
| M0_covariates | 协变量回归 | 无 |
| M1_PFC | 相同协变量回归 | 全部预定义PFC分区，逐区保留 |
| M2_distributed432 | 相同协变量回归 | 全部432分区 |
| M3_nonPFC | 相同协变量回归 | 432中PFC集合以外分区 |

M2原始特征包含M1，M1与M3互斥。独立PLS拟合的潜在空间不同，因此不能把M2/M1当作普通嵌套OLS直接做F检验。
M3检验非PFC集合单独的预测能力；M3优于M0并不能替代M2相对M1的增量比较。

## 5. 协变量处理与可复用的单次训练函数

不把协变量混入PLS成分中，以保证四模型使用同一个协变量基础预测。
对任一训练集合T及验证/测试集合V，所有拟合参数仅来自T：

1. 建立协变量设计C。重评成功的年龄使用
   `SplineTransformer(n_knots=3, degree=3, knots='quantile', include_bias=False, extrapolation='linear')`，
   产生4列年龄基函数；结点只由T确定，截距单列。连续协变量的缩放也只拟合T。
   这延续了灵活调整年龄的目标，不声称与既有m3的平滑惩罚完全相同。
2. 在T以SVD/最小二乘拟合 `a = fit(C_T, y_T)`，得到M0预测 `C_V a`。
3. 在T拟合 `B = fit(C_T, X_T)`，形成 `y_res,T=y_T−C_T a`、`X_res,T=X_T−C_T B`。
4. 对V仅应用训练参数：`X_res,V=X_V−C_V B`，不需要、也不允许用测试y计算测试残差来辅助预测。
5. 仅用T识别近零方差列（残差标准差≤1e−12），输出记录并移除；不重新改变预定义PFC归属。
6. 对X残差做训练折内标准化；`PLSRegression(scale=False)`预测y残差，保留目标原单位。
7. 最终 `y_hat,V = C_V a + PLS_hat(X_res,V)`；k=0时神经残差预测为0，等同M0。

内层每次调用均重新执行1–7，不能复用完整外层训练集上拟合的协变量调整或标准化参数。
不在全样本回归site、不按测试站点重新中心化、不采用需要测试站点标签估计批次效应的ComBat步骤。
站点只用于分组验证，既不作为连续数字输入，也不为未知测试站点估计固定效应。

接口及依据：[PLSRegression](https://scikit-learn.org/stable/modules/generated/sklearn.cross_decomposition.PLSRegression.html)、
[SplineTransformer](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.SplineTransformer.html)、
[训练/测试预处理规则](https://scikit-learn.org/stable/common_pitfalls.html)。
工程按现有环境固定scikit-learn=1.7.2实施并记录实际版本，不能因stable文档已更新而自动升级整个环境。

## 6. 嵌套 LOSO 与成分数选择

外层每次完整留出一个站点，仅用其余站点训练；每名被试仅有一组外层测试预测。
内层在外层训练站点中再次LOSO，选PLS成分数。少于3个有效站点无法执行该设计。

- 初始候选：`k=0,1,...,10`。0表示允许算法选择不使用神经信息，避免强迫加入无益特征。
- 按各内层训练集合的残差X数值秩、有效特征数及 `n_train−rank(C)−1` 限制上限。
  每个外层折取三种神经特征集、所有内层折均可拟合的共同候选集合；完整记录截断原因。
- 对每个k汇总全部内层留站点验证被试的平方误差，以**被试加权的pooled MSE最小**选k。
  完全并列（数值容差1e−10）选择较小k。不使用存在站点相关性的“fold标准误”做one-SE规则。
- M1/M2/M3分别选k，但共用候选规则与划分。不按外层成绩调k、换模型或追加筛选。
- 选定后在全部外层训练站点重新拟合完整流程，预测唯一外层测试站点。
- 输出每个内层候选的得分、选定k、训练人数/站点、秩、退化/收敛情况；失败不能静默跳过或改随机种子挑最好结果。

站点大小不均时，主指标对应当前样本中的被试加权表现；另报告站点等权的MSE/MAE及各站点结果，避免大站点掩盖异质性。
它们是不同加权目标，不能结果出来后择优更换主指标。

## 7. 性能指标与比较

把同一任务全部外层测试预测合并，主性能为：

```text
R²_M = 1 − Σ_i(y_i − y_hat_M,i)² / Σ_i(y_i − mean(y))²
ΔR²_M2−M1 = R²_M2 − R²_M1
```

这里测试y仅参与最终评分，未参与任何模型拟合。允许R²为负，不截成0。
同时输出MAE、RMSE、Pearson r（仅描述，不以其普通相关p值替代模型比较）。
附加输出各模型相对M0的ΔR²、`1−SSE_M/SSE_M0`预测误差改善指标，后者明确标为预测指标，不叫因果解释比例。
逐站点R²在n<2或目标恒定时记NA，并保留MAE/RMSE，不丢掉该站点。

核心比较固定为M2−M1；M1−M0、M2−M0、M3−M0、M2−M3作为支持性描述，报告区间但不扩展主要假设。
本版不做逐脑区显著性检验，因此没有432项BH；也不计算BF10或GAM式F/p。

## 8. 不确定性与可支持的证据强度

主要报告配对ΔR²及**站点整组重抽样、完整重拟合流程的近似95%bootstrap区间**。
站点独立性是该推断的重要前提；若站点共享被试/家系，先重新定义不可分割组。
CV训练集重叠，不能把被试误差或LOSO折分数当成独立观测直接做普通t检验。
参见 [Varoquaux, 2018](https://pubmed.ncbi.nlm.nih.gov/28655633/) 与
[Bates et al., 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11412612/)；这里的分组bootstrap是本项目拟定的近似方案，
不宣称上述论文证明了本数据情形下的精确覆盖率。

固定实施规则：

1. 从S个站点中有放回抽取S次，整站保留被试，得到各原站点的重复次数。
2. 重复站点以重复行/权重体现，但**仍使用同一个原始站点group**；绝不能给副本新站点ID，令同一被试跨训练/测试。
3. 每个重复内四模型使用相同抽样与折分，重新运行协变量处理、标准化、内层调参及外层预测。
4. 按抽样重复次数重新汇总指标及配对差异；逐重复保存结果和原因。目标正式B=2000次抽取，固定seed=20261111。
5. 抽取后有效独立站点<3、目标无变异、训练秩不足或拟合失败的重复，记录为无效，不能伪装成有效0效应。
   不静默无限重抽直到凑够2000有效样本。有效比例<95%或有效重复<1000时，保留诊断和描述性区间，关闭确认性“获支持”判定。
6. 使用有效重复的2.5%/97.5%分位数给出近似区间，记录有效数及无效比例。
   站点数少时，即便通过上述计算门槛，仍明确区间对站点组成敏感；不能靠增加bootstrap次数增加独立站点信息。
7. 实施前用不同站点规模/均值差异/协变量关联的合成数据检验：无神经信号、仅PFC信号、额外非PFC信号。
   若无增量情形频繁排除0，不启用确认性区间，先修正方法；不能拿真实数据效果决定是否通过。

B=2000可能耗时，先作小规模运行时间验证，完整任务支持按bootstrap编号分块并行、断点续跑与确定性合并；
小规模验证不能作为论文最终区间。缓存仅复用完全相同训练集合与配置的结果，不跨训练/测试边界缓存拟合参数。

重评成功主比较的95%区间下界>0，且计算/校准检查通过，作为“跨站点增量预测得到支持”的主要证据。
年龄及其他比较为次要/支持性区间，不据此宣称额外的确认性发现；不将多个95%区间称为同时置信区间。
本版不从“bootstrap差异≤0的比例”生成p值，也不把随机打乱y得到的全脑预测p值当作M2相对M1的条件增量p值。
若未来需要正式p值/多个确认性终点，应预先另定相应零假设和多重比较方案，不能结果出来后追加挑选。

## 10. 工程组织与执行顺序

沿用 `analysis/fig03/predictive_pls/` 独立模块，不改写GAM/ERQ/BF逻辑。
拟新增职责（下列正式分析文件目前尚不存在，不提供可直接执行的虚构命令）：

| 拟新增文件 | 职责 |
| --- | --- |
| `make_pfc_definition.py` | 原始PFC来源、表面匹配、面积覆盖、分区成员表和预览 |
| `models.py` | 训练折内协变量处理、残差化、标准化及PLS预测 |
| `run_pls.py` | 样本冻结、双层LOSO、k选择、OOF记录 |
| `bootstrap.py` | 按站点配对抽样、完整重拟合、可续跑结果 |
| `report_results.py` | 全精度表、Word三线表、SVG及结果读取说明 |
| `config_main.json` | 冻结全部分析选择与来源 |
| `test_pipeline.py` | 防泄漏、分组、零信号/正信号、分块合并验证 |

落地顺序：

1. 本地制作并核查PFC空间定义，保存成员表、来源、掩膜和预览图。
2. 服务器先运行现有预检，确认真实样本/站点与成功指标。
3. 冻结配置和样本快照，完成合成数据及防泄漏检查。
4. 服务器生成四模型、两任务的正式OOF预测；查看执行完整性，不据测试成绩改方案。
5. 执行完整bootstrap及有效性检查，生成性能/比较表。
6. 生成DOCX、SVG和结果说明，核对论文数字均来自同一版本OOF结果。

每批实现后提供工程文件绝对路径、服务器需要替换/新增的文件清单及当时确实可执行的命令，不打包ZIP。
